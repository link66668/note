# 六种时延计算
## 题设（统一参数，方便对比）

- 待传输**报文总长** $L = 1200$ 字节 $= 9600$ bit
- 源到目的 **h = 3 跳**，每跳带宽 $b = 100$ kbps $= 10^5$ bit/s
- **电路建立时间** $s = 10$ ms
- **分组交换/虚电路/数据报** 把报文切成小组，**每个分组长 $p = 240$ bit**（含首部）
- **忽略传播、排队、处理时延**（本题明确"忽略"，故 $h\,t$ 一般不参与；为严谨此处也忽略传播）

先算基础量：
- 报文发送时间能力：$L / b = 9600 / 10^5 = 0.096\,\text{s} = 96\,\text{ms}$
- 分组数 $n = L / p = 9600 / 240 = 40$ 个
- 单个分组发送时延 $= p / b = 240 / 10^5 = 0.0024\,\text{s} = 2.4\,\text{ms}$

---

## 第一套：虚电路 / 数据报 / 电路转发（你问的那道题）

### ① 虚电路
先建逻辑连接（有建连开销 $s$），然后分组沿固定路径发送。

$$T_{VC} = s + \frac{L}{b} + \underbrace{(h-1)\frac{p}{b}}_{\text{中间节点存储转发}} = 10 + 96 + (3-1)\times 2.4 = 10 + 96 + 4.8 = \boxed{110.8\,\text{ms}}$$

### ② 数据报（数据包 / 分组交换）
不建连接，每分组独立选路、存储转发。[cite:be9aa955-4]

$$T_{datagram} = \frac{L}{b} + (h-1)\frac{p}{b} = 96 + 4.8 = \boxed{100.8\,\text{ms}}$$

### ③ 电路转发（电路交换）
先建立专用通路（$s$），然后整条连续报文一次送达，无中间分组转发。[cite:be9aa955-4]

$$T_{circuit} = s + \frac{L}{b} = 10 + 96 = \boxed{106\,\text{ms}}$$

---

## 第二套：分组交换 / 报文交换 / 电路交换（经典三分法）

### ④ 分组交换 —— 与②相同（数据报就是分组交换的标准形式）
$$T_{packet} = \frac{L}{b} + (h-1)\frac{p}{b} = 100.8\,\text{ms} = \boxed{100.8\,\text{ms}}$$

### ⑤ 报文交换
以**完整报文**为单位，每个节点收完整报文再转发，故每一跳都要发送整条 $L$。[cite:be9aa955-3]

$$T_{message} = h \times \frac{L}{b} = 3 \times 96 = \boxed{288\,\text{ms}}$$

> 对比：报文交换比分组交换慢得多，因为分组能"流水线"层层转发，报文必须整条到齐再走下一跳。[cite:be9aa955-1]

### ⑥ 电路交换 —— 与③相同的原理
$$T_{circuit}= s + \frac{L}{b} = \boxed{106\,\text{ms}}$$

---

## 六个结果总表

| 方式 | 计算过程 | 总时延 |
|---|---|---:|
| ① 虚电路 | 10 + 96 + 4.8 | **110.8 ms** |
| ② 数据报 | 96 + 4.8 | **100.8 ms** |
| ③ 电路转发 | 10 + 96 | **106 ms** |
| ④ 分组交换 | 96 + 4.8 | **100.8 ms**（=②）|
| ⑤ 报文交换 | 3 × 96 | **288 ms** |
| ⑥ 电路交换 | 10 + 96 | **106 ms**（=③）|

---

## 关键结论（答题可直接用）

1. **虚电路与数据报都属于分组交换**，区别只在"要不要建连"：虚电路多一个建连时间 $s$，数据报没有。[cite:f09d2622-1]
   - 本题：**数据报（100.8ms）< 电路转发（106ms）< 虚电路（110.8ms）** —— 因为数据报免了建连，但又比"整段直达的电路"多了中间分组转发时延；虚电路则两者都有。

2. **报文交换最慢（288ms）**：每跳都要整条转发，无法流水线。

3. **②=④，③=⑥**：它们在数学上完全等价，只是"问法"不同（第一套强调服务模式，第二套强调交换技术）。

4. 若 **忽略传播排队处理且电路建立时间 $s$ 较长**，虚电路/电路转发会明显更慢；若 $s=0$，则三者排序会变化——**因此具体排序取决于题给数值**。
