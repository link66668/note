# 错题本编写要求

> 本要求规定错题本的建立位置、收录范围和单条错题的记录方式。用户明确要求记录错题时启用；启用后，冲突部分以本要求为准，无冲突部分继续遵循[[通用要求]]。

## 主要内容

- 触发条件
- 错题本的位置与命名
- 单条错题的内容
- 组织方式
- 编辑流程与检查清单

---

## 一、触发条件

- 用户在对话中明确要求“记录错题”“记到错题本”“这道题记一下”等，并给出或指定具体题目时启用。
- 只做知识讲解、解题、推导或辨析，没有要求写入文件时，不创建也不修改错题本，不因对话中出现错题就自动记录。
- 用户明确指定了其他文件时，以用户指定为准。
- 同一请求同时包含知识回答与错题记录时，回答部分遵循对应科目根目录的问答要求文件；写入部分遵循本要求和[[通用要求]]。

---

## 二、错题本的位置与命名

- 每个科目在**科目根目录**使用一个固定文件 `错题本.md`，一个科目只有一份。
- 当前时期科目直接使用仓库根目录下的科目文件夹；已结束时期科目使用时期文件夹内的科目文件夹。
- 错题本放在科目根目录，不放入 `原件`、`笔记`、`真题整理` 等子目录，也不放在仓库根目录或 `要求` 文件夹。
- 不同科目的错题不混放；同一道错题涉及多个科目时，放入主要归属科目，并用 `related` 或正文 wikilink 连接其他科目。
- 科目尚无错题本时，按[[通用要求]]新建并补全 frontmatter：

```yaml
---
title: 错题本
course: 科目名
tags:
  - 科目标签
  - 错题本
created: YYYY-MM-DD
related:
  - "[[对应章节笔记]]"
---
```

---

## 三、单条错题的内容

每条错题必须包含**原题**与**正确解法**；**错误解法**只在用户说明或要求时才写。

1. **原题**（必备）：题干完整照录，包含条件、数据、公式、选项、图示文字与全部子问题，并标注来源（教材、章节、试卷或题号）。
2. **正确解法**（必备）：给出完整、可复核的解答过程。
3. **错误解法**（可选）：如实记录当时的原始做法，包括错误的替换、漏掉的讨论、跳过的步骤和由此得到的结果；不美化、不补全，不改写成“接近正确”的形式。用户没有提供时不得编造，直接省略这一部分。

- 错题本默认只记录上述内容，**不添加错因分析、教训、方法总结等内容**；用户明确要求补充时再追加。
- 原题题干放在 Callout 外；错误解法写成加粗标题小节，与正确解法区分开。
- 正确解法使用默认折叠的 Answer Callout，标题写明“正确解法”；Callout 内每一行，包括空行、公式和表格，都必须带 `>`。
- 来源已有标准解答时，注明“原书解答”“参考答案”或“试卷答案”；自己核验的部分注明核验方式，新增内容标注“AI 补充”。
- 来源没有答案时不得编造，写明“暂无参考答案”。
- 同一道题重复出错时，在原条目下追加新的错误记录，不新建重复条目。

---

## 四、组织方式

- 错题本按知识主题或章节划分 H1 模块，模块之间用 `---` 分隔；同一模块内按记录顺序排列。
- 单条错题用加粗的“错题 n”编号引出，例如 `**错题 1**：`，不把完整题干或长公式写进标题。
- 需要细分时使用 H2、H3；标题层级最多到 H3，禁止 H4 及更深标题，也不得标题跳级。
- 新错题追加到对应模块末尾；模块不存在时新建模块，不重排已有条目。
- 每条错题的来源使用 wikilink 链接回对应章节笔记或来源文件。

---

## 五、编辑流程与检查清单

1. 确认题目归属科目与对应章节笔记。
2. 定位或新建该科目的 `错题本.md`。
3. 照录原题并标注来源。
4. 用户提供了错误解法时，照录其原文。
5. 写出正确解法；只有用户要求时才追加错因分析、教训等内容。
6. 检查 frontmatter、标题层级、公式定界符、Callout 与 wikilink。

- [ ] 错题本位于对应科目根目录，文件名为 `错题本.md`
- [ ] 原题完整，无漏条件、漏子问题、漏选项
- [ ] 用户提供错误解法时，已如实保留、未改写或美化
- [ ] 正确解法完整、可复核
- [ ] 未添加用户没有要求的错因分析、教训等内容
- [ ] 公式定界符成对且内侧无空格，表格为原生管道表格
- [ ] 标题层级不超过 H3，无标题跳级
- [ ] 来源与相关章节使用 wikilink 连接

## 本要求小结

| 项目 | 核心要求 |
|---|---|
| 触发 | 用户明确要求记录错题时启用 |
| 位置 | 各科目根目录下的 `错题本.md`，一个科目一份 |
| 必备内容 | 原题与正确解法；错误解法按用户要求提供时才写 |
| 默认范围 | 只记录题目本身；错因分析、教训等内容按用户要求另加 |
| 组织 | 按主题或章节分 H1 模块，新条目追加不重排 |
| 依据 | 冲突时以本要求为准，其余遵循[[通用要求]] |
