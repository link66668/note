# 总复习编写要求

> 本要求适用于文件名（不含路径和 `.md` 扩展名）为 `总复习` 的 Markdown 文件，用于把用户筛选出的复习知识点整理成可直接阅读、背诵和查题的总复习资料。除用户另有明确要求外，`总复习.md` 还必须遵循 [[通用要求]] 中的通用 Markdown、frontmatter、公式、表格、链接和发布前检查规范。

## 主要内容

- 总复习文件的定位
- 用户知识点的处理原则
- 大章节归并规则
- 章节考题的全量收录规则
- 章节考题按题目类型分类的规则
- 章节考题答案的折叠隐藏规则
- 主观题考点与复习知识点的覆盖核对规则
- 真题来源与题干保留要求
- Markdown 结构模板
- 整理流程与检查清单

---

## 一、文件定位

1. `总复习.md` 是**直接提供给用户阅读和复习的汇总文件**，不是整理过程记录、工作日志或资料索引。
2. 正文应以知识点和考题为主体，避免加入与复习无关的处理说明、长篇方法解释或 AI 工作过程。
3. 内容应清晰、紧凑、可检索，使用户能够按章节复习知识点，并在章内按题目类型查看该章出现过的全部考题。

---

## 二、用户知识点处理原则

> [!important] 用户列出的知识点是复习范围基线
> 用户已经筛选并列出的知识点，代表用户真正需要复习的内容。整理时**不受用户原有格式、标题、顺序、列表形式或段落划分的限制**，应在不增加、删除、替换或改变知识内容的前提下，重构为更合理、更易复习的 Markdown 格式。

1. **完整保留**：  
   用户列出的概念、问题、公式、表格、算法名称、计算步骤、示例和待复习提示均须保留。
2. **忽略原格式，重新组织**：  
   用户原有的标题层级、编号、段落顺序、列表符号、表格形式和空行仅作为输入形式，不是最终排版要求。可以拆分或合并段落、重建标题、调整顺序、把并列内容改为列表或表格，并把零散内容移动到正确的大章节。
3. **内容等价是唯一边界**：  
   无论怎样重构格式，整理结果都必须与用户原内容信息等价。不得增加新的知识结论，不得删去已有概念、问题、条件、限定词、公式、算法名、示例或待复习提示，也不得改变原意和考查重点。
4. **按知识逻辑而非原顺序排列**：  
   同一章节内部可以按照“定义或密码体制 → 参数与符号 → 原理或流程 → 性质与安全性 → 计算与应用 → 待复习问题”的顺序重新排列；来源内容不完整时，只整理现有内容，不擅自补齐缺失部分。
5. **选择最合适的 Markdown 结构**：  
   - 并列概念或待复习项目使用列表。
   - 对比信息使用 Markdown 管道表格。
   - 定义、定理和核心结论使用块引用或 Callout。
   - 算法步骤使用有序列表。
   - 公式使用 LaTeX。
   - 简短提示可以改写为明确的“复习问题”，但不能替用户回答或扩充内容。
6. **不得用真题反向补知识点**：  
   某道考题属于本章，并不代表要把该题涉及的所有内容补写到知识点部分。知识点范围和考题收录范围彼此独立。
7. **不得擅自删去简略提示**：  
   用户写下的“掌握流程”“如何选择工作模式”“如何求逆矩阵”等简略提示仍是有效复习要求，不能因其不是完整正文而删除。
8. **补充必须得到授权**：  
   只有用户明确要求补全讲解、答案或推导时，才可以增加知识内容；新增内容必须按 [[通用要求]] 标明为 AI 补充。

## 三、大章节归并规则

> [!important] 一个大章节使用一个标题
> 同一课程大章节可能对应多份课件笔记或多个小节文件。在 `总复习.md` 中，应将它们归并到同一个大章节标题下，不按源文件数量重复建立同级标题。

1. 整篇总复习文件只保留一个 H1，作为文件标题。
2. 每个课程大章节使用一个 H2，例如：
   - `## 一、现代密码学概述（第 1 章）`
   - `## 二、古典密码体制与密码分析（第 2 章）`
   - `## 三、Shannon 理论与密码学安全性（第 3 章）`
   - `## 四、有限域基础与分组密码（第 4 章）`
3. 同一大章节下的知识模块使用 H3，不再为每份来源笔记建立新的 H2。H3 应依据知识逻辑重新设计，不必沿用用户原先的标题或源文件标题。
4. **示例**：分组密码即使由“分组密码（一）”“分组密码（二）”“分组密码（三）”三份笔记组成，也只建立一个“分组密码”大章节标题；三份笔记的内容在该标题下按知识模块排列。
5. 大章节之间使用分隔线 `---`，但不得为了视觉效果滥用空行或更深层级标题。

## 四、章节考题收录规则

> [!important] 按章节范围收录，而不是按已列知识点筛题
> 只要一道考题属于某个大章节的教学范围，就必须列入该章节的考题部分。该题不需要与用户在知识点部分列出的内容直接对应。

> [!important] 章内必须按题目类型分类
> 每章的考题先归入 `### 本章考题`，再按判断题、单项选择题、多项选择题、填空题、名词解释题、简答题、论述题、证明题、计算题、材料分析题、综合题、应用题等题目类型分类。**题目类型是章内考题的第一分组依据，不得再以试卷或来源文件作为第一分组依据。**

1. **整章判断**：  
   判断题目属于哪个大章节时，以课程章节体系、题目主要考查对象和课程笔记内容为依据。
2. **不受知识点列表限制**：  
   即使用户没有把某个考点写入知识点部分，只要真题属于该章，仍需列出题目；但不得因此自动补写该考点的知识讲解。
3. **全量搜索真题整理目录**：  
   必须检查课程 `真题整理` 目录内的全部 Markdown 文件，不得只搜索文件名或只查看某几份试卷。
4. **题型全部纳入**：  
   判断题、选择题、填空题、简答题、证明题、计算题、综合题和应用题，只要属于该章，均须收录。
5. **按题目类型分类**：  
   同一章节内的考题必须按题目类型集中排列。单项选择题与多项选择题应分别分类；材料分析题、论述题、综合题等来源已明确标注的题型应保留原题型名称。某一类型没有题目时不建立空分类。
6. **题型判断顺序**：  
   来源明确标注题型时，以来源标注为准；来源没有标注时，根据主要作答方式判断。含多个不同类型子问题且不可安全拆分的题目归入“综合题”，不得为分类而拆散材料、条件或子问题。
7. **题型分类的 Markdown 层级**：  
   `### 本章考题` 使用 H3，各题型统一使用 H4，例如 `#### 一、单项选择题`、`#### 二、简答题`，不得使用加粗分类行或 H5 及更深标题。本条符合 [[通用要求]] 中“允许 H4、禁止 H5 及更深标题”的层级规则。默认顺序为“判断题 → 单项选择题 → 多项选择题 → 填空题 → 名词解释题 → 简答题 → 论述题 → 证明题 → 计算题 → 材料分析题 → 综合题 → 应用题 → 其他题型”；只列实际存在的题型。来源或用户另有明确顺序要求时从其要求。
8. **题内标注来源**：  
   因考题不再按来源文件分组，每道题都必须单独标注来源 wikilink；同一题型中的题目可来自不同试卷或复习资料，但来源不得省略或只在题型标题处统一标注。
9. **跨章题目**：  
   一道题同时综合多个章节时，放在主要考查章节；确有必要时可在另一个章节用 wikilink 或“跨章节综合题”提示引用，避免无说明地重复整道题。
10. **重复考题**：  
   同一考点或相同题干在不同试卷中出现时，放入相同题型分类，并按不同来源分别保留，以反映考查频率；不得因题干重复而合并来源或删除其中一题。
11. **复习资料题**：  
   位于 `真题整理` 中但不能确认来自正式试卷的题目仍可收录，应按其实际题型归类，并逐题标明“复习资料题”“模拟题”或其真实资料类型，不得另设“复习资料题”来替代题型分类，也不得冒充历年真题。
12. **同一题型内的排列顺序**：  
   默认先列正式真题，再列模拟题、复习资料题和来源未确认题；同一资料性质下按学年或来源时间由旧到新排列。用户明确要求其他顺序时，以用户要求为准。
13. **有答案时必须折叠收录**：  
   章节考题在来源文件中附有答案时，必须在对应题目后完整保留答案，并统一使用 Obsidian 可折叠 Answer Callout：`> [!answer]-`。减号 `-` 表示答案默认折叠，避免读题时直接暴露答案；来源没有答案时只保留题干，不得自行编造答案。

## 五、主观题考点遗漏核对规则

> [!important] “大题”统一指所有主观题
> 在总复习任务中，用户所说的“大题”统一指**所有主观题**，不按分值大小或题目篇幅区分。名词解释题、简答题、论述题、证明题、计算题、计算分析题、材料分析题、综合题、应用题，以及其他需要组织文字、推导、论证或计算作答的题型，均属于本规则所称的主观题。

> [!important] 每章都要核对主观题考点是否被复习知识点覆盖
> 完成章节考题收录后，必须逐章检查该章全部主观题的核心考点是否已在该章的用户复习知识点中明确列出。这里的“全部主观题”包括正式真题、模拟题、复习资料题和来源未确认的自测题；不得只核对正式试卷，也不得只检查简答题或论述题。

1. **按考点实质判断覆盖情况**：  
   不要求知识点与题干逐字相同，但复习知识点必须明确包含完成该题所需的核心概念、条件、关系、公式、步骤、方法或论证对象。只有宽泛的章节名称、无法对应题目作答要求的概括性标题，不能视为已覆盖。
2. **逐题核对后按考点去重**：  
   每道主观题都必须参与核对。同一遗漏考点被多道题重复考查时，遗漏提示中可以合并为一个项目，但题目本身仍须按照不同来源在“本章考题”中分别保留。
3. **遗漏只作备注，不自动补写知识**：  
   若发现主观题考点未被用户复习知识点覆盖，应在该章知识点之后、`### 本章考题` 之前添加 `> [!warning] 主观题知识点遗漏` Callout。除非用户另行明确要求补充讲解或答案，否则只标明遗漏考点，不得把题目答案、教材内容或 AI 补充内容反向写入知识点部分。
4. **遗漏项目必须标明题目来源**：  
   每个遗漏考点后应使用 wikilink 标明至少一道对应题目的来源；同一遗漏考点涉及多个重要来源时可以并列标明。正式真题、模拟题、复习资料题和来源未确认题仍应如实区分。
5. **没有遗漏时不建立空提示**：  
   某章全部主观题考点均已被知识点覆盖时，不添加空的“主观题知识点遗漏”Callout，也不写无必要的处理日志。
6. **题库变化后重新核对**：  
   新增、删除、筛选或移动章节考题后，必须以当前总复习实际保留的主观题为准重新执行覆盖核对，及时增加、更新或删除遗漏备注。

标准格式：

```markdown
> [!warning] 主观题知识点遗漏
> 对照本章全部主观题（含正式真题、模拟题、复习资料题和来源未确认题）后，以下考点未在上述复习知识点中明确列出。此处仅作遗漏标记，不补写答案：
> - 遗漏考点一：[[课程/真题整理/来源文件|题目来源]]。
> - 遗漏考点二：[[课程/真题整理/另一来源|另一题目来源]]。
```

## 六、题干与来源要求

1. **题干完整**：  
   完整保留题目条件、参数、公式、矩阵、表格、选项、空格和所有子问题，不得只写考点名称代替题目。
2. **来源明确**：  
   每道题都必须在题干后单独使用 wikilink 标明来源文件。即使同一题型中连续多题来自同一份试卷，也不得只在整组题目前统一标注一次来源。例如：

   ```markdown
   1. 【单项选择题，2 分】完整题干。  
      **来源**：[[课程/真题整理/2025—2026 学年期末试卷（A 卷）|2025—2026 学年期末 A 卷]]  
      **资料性质**：正式真题
   ```

3. **保留分值和题型**：  
   来源中给出题型、题号或分值时，应一并保留，例如“【简答题，5 分】”。
4. **不伪造来源**：  
   无法从真题整理文件确认来源的题目，只能标为“原笔记已有自测题”或“来源未确认”，不得自行推断学年、试卷或分值。
5. **答案使用折叠 Callout**：  
   来源中存在答案时，应紧跟对应题目，使用 `> [!answer]-` 格式完整收录并默认折叠。Callout 标题应注明答案性质，例如“原题参考答案”“原网页参考答案”“手写参考答案（待核验）”或“原卷作答”；不得把答案直接平铺在题干后，也不得把手写答案、原卷作答或 AI 解答冒充标准答案。
6. **疑点忠实保留**：  
   原题数据矛盾、概率和不为 1、OCR 不清或公式疑似错误时，不得静默修正；应保留原题并使用 Warning Callout 说明疑点。

答案 Callout 的标准格式：

```markdown
1. 【题型，分值】完整题干。  
   **来源**：[[课程/真题整理/某学年试卷|某学年试卷]]  
   **资料性质**：正式真题

> [!answer]- 原网页参考答案
> 答案正文。
>
> 多段答案的每一段、列表、公式、表格和代码块都必须保持在引用范围内，即每行继续使用 `>`。
```

- Callout 类型固定使用 `answer`，并在 `]` 后保留减号 `-`，不得改为默认展开的 `> [!answer]` 或 `> [!answer]+`。
- 答案包含多段文字、列表、公式、表格或代码时，所有内容行都必须添加引用标记 `>`，避免答案内容脱离折叠区域。
- 同一道题有多个来源答案时，应在同一个折叠 Callout 中分别标明来源；若答案彼此冲突，还应在 Callout 后增加 Warning Callout 说明疑点。
- 来源只提供答案选项、简短结论或不完整步骤时，应按原有完整程度收录，不得擅自补成完整解答。

## 七、知识点与考题的章节结构

每个大章节按以下顺序组织：

1. 该章中用户原先列出的复习知识点。
2. 若存在主观题考点遗漏，在知识点之后添加 `> [!warning] 主观题知识点遗漏`；没有遗漏时省略该 Callout。
3. `### 本章考题`。
4. 在“本章考题”下按题目类型设置 H4 分类标题；只建立实际存在题目的类型。
5. 各题型内部默认按“正式真题 → 模拟题 → 复习资料题 → 来源未确认题”排列，同类资料再按时间顺序排列。
6. 每道题在题干后单独标明来源 wikilink 和资料性质。
7. 题目有来源答案时，紧跟使用 `> [!answer]-` 折叠答案。
8. 来源未确认的自测题仍按实际题型归类，并在题内标明“来源未确认”，不得另建一个取代题型分类的来源分组。

推荐结构：

```markdown
## 一、章节名称（第 n 章）

### 1. 用户列出的知识点一

原有内容……

### 2. 用户列出的知识点二

原有内容……

> [!warning] 主观题知识点遗漏
> 对照本章全部主观题后，以下考点未在上述复习知识点中明确列出。此处仅作遗漏标记，不补写答案：
> - 遗漏考点：[[课程/真题整理/来源文件|题目来源]]。

### 本章考题

#### 一、单项选择题

1. 【单项选择题，2 分】完整题干。  
   **来源**：[[课程/真题整理/某学年试卷|某学年试卷]]  
   **资料性质**：正式真题
   - A. 选项一
   - B. 选项二
   - C. 选项三
   - D. 选项四

> [!answer]- 原题参考答案
> B。

2. 【单项选择题】完整题干。  
   **来源**：[[课程/真题整理/某复习资料|某复习资料]]  
   **资料性质**：复习资料题

#### 二、简答题

1. 【简答题，5 分】完整题干。  
   **来源**：[[课程/真题整理/另一学年试卷|另一学年试卷]]  
   **资料性质**：正式真题

> [!answer]- 原题参考答案
> 答案正文。
```

## 八、整理流程

1. 完整阅读 [[通用要求]]。
2. 完整读取待整理的复习文件，提取用户已经列出的全部知识点；原有格式和顺序不作为最终结构依据。
3. 确认课程大章节与源笔记、小节文件之间的对应关系。
4. 将用户知识点归并到相应大章节，并按知识逻辑重新设计标题、顺序、列表、表格和公式布局；重构前后逐项建立内容对应关系。
5. 遍历课程 `真题整理` 目录中的全部 Markdown 文件。
6. 逐题判断所属章节，不以用户知识点列表作为筛选条件。
7. 在每章的 `### 本章考题` 下逐题判断题目类型；来源已标注题型时保留原标注，来源未标注时按主要作答方式分类。
8. 将题目按章节和题目类型写入总复习文件；题型统一使用 H4 分类标题，不按来源文件建立第一层分组。
9. 在每道题后单独标注来源 wikilink 和资料性质，完整保留题干、题号、分值、选项、条件、公式、表格与子问题。
10. 检查每道题在来源中是否附有答案；有答案时紧跟题目使用 `> [!answer]-` 完整收录，并标明答案性质和来源；无答案时不得编造。
11. 对重复题、跨章题、复习资料题和来源不明题作出明确标注；重复题在相同题型中按各自来源分别保留。
12. 逐章识别全部主观题，包括正式真题、模拟题、复习资料题和来源未确认的自测题，不得把“大题”误解为仅限论述题、分值较高的题目或正式试卷中的题目。
13. 逐题核对主观题核心考点是否已被该章复习知识点覆盖；未覆盖时在知识点之后、`### 本章考题` 之前添加“主观题知识点遗漏”Warning Callout，按考点去重并标明对应来源，不补写答案。
14. 对照原复习文件检查知识点零丢失，对照真题整理文件检查题目和已有答案零遗漏。
15. 检查 Markdown、YAML、公式、表格、wikilink、Callout 和标题层级，并确认题型分类完整、每题来源明确、主观题遗漏备注准确、Answer Callout 默认折叠且内容没有脱离引用范围。

## 本章小结

| 项目 | 核心要求 |
|---|---|
| 文件用途 | 面向用户直接复习的总复习资料 |
| 知识点范围 | 以用户已经列出的内容为准 |
| 原始格式 | 不受原格式限制，按知识逻辑重构 |
| 重构边界 | 只改变组织与呈现方式，不改变知识内容 |
| 章节结构 | 一个大章节一个 H2，同章多份笔记合并 |
| 考题范围 | 凡属于该章节的题目全部列出，不受知识点列表限制 |
| 考题分类 | 每章在 `### 本章考题` 下按题目类型分类，题型统一使用 H4，不按来源文件作第一分组 |
| 主观题覆盖核对 | “大题”指全部主观题；逐章核对其考点是否被复习知识点覆盖，遗漏时用 Warning Callout 标注来源，不自动补写答案 |
| 题目来源 | 遍历全部真题整理文件，每道题后单独用 wikilink 标注来源和资料性质 |
| 答案呈现 | 来源有答案时使用 `> [!answer]-` 默认折叠，并注明答案性质 |
| 内容完整性 | 知识点零丢失、章节考题零遗漏、题干条件零删减 |
| 来源可信度 | 正式真题、复习资料题与来源未确认题明确区分 |
