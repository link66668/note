# 可分离变量方程

$$\varphi_{1}(x)\psi_{1}(y)\mathrm{d}x+\varphi_{2}(x)\psi_{2}(y)\mathrm{d}y=0\quad\Longleftrightarrow\quad\frac{\varphi_{1}(x)}{\varphi_{2}(x)}\mathrm{d}x=-\frac{\psi_{2}(y)}{\psi_{1}(y)}\mathrm{d}y,$$

两端积分即得通解

$$\int\frac{\varphi_{1}(x)}{\varphi_{2}(x)}\mathrm{d}x=-\int\frac{\psi_{2}(y)}{\psi_{1}(y)}\mathrm{d}y+C.$$

- 分离时除去的因子 $\varphi_{2}(x)\psi_{1}(y)$ 可能对应不在通解中的解，须单独检验并补入。
- 出现 $\dfrac{f'(x)}{f(x)}$、$\dfrac{g'(y)}{g(y)}$ 时直接积成 $\ln|f(x)|$、$\ln|g(y)|$，绝对值不能省。

依据红书 §4.2 题型一 1：[[数学竞赛/红书/各章节/第4章 常微分方程#1. 可分离变量方程的解法]]。

# 齐次方程

$$y'=\varphi\left(\frac{y}{x}\right),\qquad u=\frac{y}{x}\ \Longrightarrow\ y=ux,\quad y'=u+xu',$$

代入后化为关于 $u$ 的可分离变量方程。

- 形如 $y'=f\left(\dfrac{a_{1}x+b_{1}y+c_{1}}{a_{2}x+b_{2}y+c_{2}}\right)$ 且 $a_{1}b_{2}\neq a_{2}b_{1}$ 时，令 $x=u+\alpha,\ y=v+\beta$（$(\alpha,\beta)$ 为两条直线 $a_{1}x+b_{1}y+c_{1}=0$、$a_{2}x+b_{2}y+c_{2}=0$ 的交点），化为齐次方程。
- $a_{1}b_{2}=a_{2}b_{1}$ 时令 $u=a_{2}x+b_{2}y$，方程直接化为可分离变量方程 $\dfrac{\mathrm{d}u}{\mathrm{d}x}=a_{2}+b_{2}f\left(\dfrac{ku+c_{1}}{u+c_{2}}\right)$。
- 分离变量后出现 $\dfrac{\mathrm{d}x}{x}$ 时积成 $\ln|x|$；$x>0$ 与 $x<0$ 两段常需分开写，合并时用 $\operatorname{sgn}(x)\ln|x|$。

依据红书 §4.2 题型一 2：[[数学竞赛/红书/各章节/第4章 常微分方程#2. 齐次方程的解法]]。

# 一阶线性方程

$$\frac{\mathrm{d}y}{\mathrm{d}x}+P(x)y=Q(x)\quad\Longrightarrow\quad y=\mathrm{e}^{-\int P(x)\mathrm{d}x}\left[\int Q(x)\mathrm{e}^{\int P(x)\mathrm{d}x}\mathrm{d}x+C\right].$$

- 方程对 $y$ 非线性、但把 $x$ 视为未知函数后形如 $\dfrac{\mathrm{d}x}{\mathrm{d}y}+P(y)x=Q(y)$ 时，对 $x$ 直接用同一公式。
- $\int P(x)\mathrm{d}x$ 取任意一个原函数即可，常数并入 $C$；$P,Q$ 连续即保证解在所在区间上存在。
- 遇到 $\int\mathrm{e}^{-x^{2}}\mathrm{d}x$ 这类不可积积分，结果用变上限积分表示，不必强行求出原函数。

依据红书 §4.2 题型一 3：[[数学竞赛/红书/各章节/第4章 常微分方程#3. 一阶线性微分方程的解法]]。

# Bernoulli 方程

$$\frac{\mathrm{d}y}{\mathrm{d}x}+P(x)y=Q(x)y^{n}\quad(n\neq0,1),\qquad u=y^{1-n}\ \Longrightarrow\ \frac{\mathrm{d}u}{\mathrm{d}x}+(1-n)P(x)u=(1-n)Q(x).$$

- 解出 $u$ 后回代 $u=y^{1-n}$ 得通解；$n>0$ 时 $y=0$ 也是解，通常不在通解中。
- 代换的作用是把 $y^{n}$ 项消成关于 $u$ 的一次项；$n=0,1$ 时方程本身已是一阶线性或可分离变量方程。

依据红书 §4.2 题型一 3：[[数学竞赛/红书/各章节/第4章 常微分方程#3. 一阶线性微分方程的解法]]。

# 全微分方程与积分因子

> 若存在二元函数 $\varphi(x,y)$ 使 $\mathrm{d}\varphi=P\mathrm{d}x+Q\mathrm{d}y$，则 $P\mathrm{d}x+Q\mathrm{d}y=0$ 的通解为 $\varphi(x,y)=C$。当 $P,Q$ 在单连通域内具有一阶连续偏导数时，该方程为全微分方程的充要条件是
> $$\frac{\partial P}{\partial y}=\frac{\partial Q}{\partial x}.$$

- 求 $\varphi$ 有三法：凑全微分、不定积分（由 $\dfrac{\partial\varphi}{\partial x}=P$ 积分后再定待定函数）、与路径无关的曲线积分；常用凑微分公式见 [[数学竞赛/结论#七、常见全微分公式（凑微分）]]。
- 若 $\dfrac{1}{Q}\left(\dfrac{\partial P}{\partial y}-\dfrac{\partial Q}{\partial x}\right)$ 只依赖于 $x$，则方程有只含 $x$ 的积分因子 $\mu(x)=\mathrm{e}^{\int\frac{1}{Q}\left(\frac{\partial P}{\partial y}-\frac{\partial Q}{\partial x}\right)\mathrm{d}x}$。
- 若 $\dfrac{1}{P}\left(\dfrac{\partial Q}{\partial x}-\dfrac{\partial P}{\partial y}\right)$ 只依赖于 $y$，则方程有只含 $y$ 的积分因子 $\mu(y)=\mathrm{e}^{\int\frac{1}{P}\left(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right)\mathrm{d}y}$。

依据红书 §4.2 题型一 4：[[数学竞赛/红书/各章节/第4章 常微分方程#4. 基于全微分方程的解法]]。

# 可降阶的高阶方程

$$y^{(n)}=f(x)\ \Longrightarrow\ \text{逐次积分 }n\text{ 次};$$

$$y''=f(x,y')\ \Longrightarrow\ \text{令 }y'=p,\ y''=\frac{\mathrm{d}p}{\mathrm{d}x},\ \text{化为 }\frac{\mathrm{d}p}{\mathrm{d}x}=f(x,p);$$

$$y''=f(y,y')\ \Longrightarrow\ \text{令 }y'=p,\ y''=p\frac{\mathrm{d}p}{\mathrm{d}y},\ \text{化为 }p\frac{\mathrm{d}p}{\mathrm{d}y}=f(y,p).$$

- 每积分一次补一个任意常数，$n$ 阶方程的通解含 $n$ 个独立常数。
- 求特解时边积分边代入初始条件定常数，比全部积完再代简单。
- 不显含 $x$ 的方程以 $y$ 为自变量，先解出 $p=p(y)$，再解 $\dfrac{\mathrm{d}y}{\mathrm{d}x}=p(y)$。

依据红书 §4.2 题型二 1：[[数学竞赛/红书/各章节/第4章 常微分方程#1. 几种可降阶的高阶微分方程的解法]]。

# 线性方程解的结构

> 设 $y''+P(x)y'+Q(x)y=f(x)$ 为非齐次方程，其对应的齐次方程为 $y''+P(x)y'+Q(x)y=0$，则
>
> 1. 两个非齐次解之差是齐次解；
> 2. 齐次解的任意线性组合 $C_{1}y_{1}+C_{2}y_{2}$ 仍是齐次解；
> 3. 一个非齐次解与一个齐次解之和仍是非齐次解；
> 4. 齐次方程的两个线性无关解 $y_{1},y_{2}$ 给出齐次通解 $y=C_{1}y_{1}+C_{2}y_{2}$，非齐次方程通解为 $y=y^{*}+C_{1}y_{1}+C_{2}y_{2}$，其中 $y^{*}$ 是一个非齐次特解；
> 5. 自由项 $f=f_{1}+f_{2}$ 时，分别以 $f_{1},f_{2}$ 为自由项的两个特解之和是非齐次方程的特解。

- 已有一个齐次特解 $y_{1}$ 时，令 $y_{2}=y_{1}u$ 代入降阶，得 $u''+\left(2\dfrac{y_{1}'}{y_{1}}+P\right)u'=0$，先解 $u'$ 再积分。
- 线性无关的判据是两个解之比不为常数；$y_{1},y_{2}$ 线性无关时 $W=y_{1}y_{2}'-y_{1}'y_{2}\neq0$。
- 上述结构对 $n$ 阶线性方程同样成立，独立常数增加到 $n$ 个。

依据红书 §4.2 题型二 2：[[数学竞赛/红书/各章节/第4章 常微分方程#2. 高阶线性微分方程解的结构及其应用]]。

# 二阶常系数齐次线性方程

特征方程 $\lambda^{2}+a\lambda+b=0$ 的根决定 $y''+ay'+by=0$ 的通解：

| 特征根 | 通解 |
|---|---|
| 相异实根 $\lambda_{1}\neq\lambda_{2}$ | $y=C_{1}\mathrm{e}^{\lambda_{1}x}+C_{2}\mathrm{e}^{\lambda_{2}x}$ |
| 二重根 $\lambda_{1}=\lambda_{2}=\lambda$ | $y=(C_{1}+C_{2}x)\mathrm{e}^{\lambda x}$ |
| 共轭复根 $\alpha\pm\mathrm{i}\beta$ | $y=\mathrm{e}^{\alpha x}\left(C_{1}\cos\beta x+C_{2}\sin\beta x\right)$ |

- 重根情形的 $x$ 因子不能漏；复根情形必须写成实函数，且 $\cos$ 与 $\sin$ 的系数相互独立。
- 特征根为纯虚数 $\pm\mathrm{i}\beta$ 时通解为 $C_{1}\cos\beta x+C_{2}\sin\beta x$。
- 高阶常系数齐次方程用同一特征根法：一个 $k$ 重实根 $\lambda$ 贡献 $\mathrm{e}^{\lambda x}$ 乘 $k-1$ 次任意多项式；一对 $k$ 重共轭复根 $\alpha\pm\mathrm{i}\beta$ 贡献 $\mathrm{e}^{\alpha x}$ 乘 $k-1$ 次任意多项式与 $\cos\beta x$、$\sin\beta x$ 的乘积组合。

依据红书 §4.2 题型二 3：[[数学竞赛/红书/各章节/第4章 常微分方程#3. 二阶常系数线性微分方程的解法]]。

# 二阶常系数非齐次线性方程

通解为 $y=Y+y^{*}$：先求齐次方程通解 $Y$，再求一个特解 $y^{*}$，最后按初始条件定常数。

$$f(x)=P_{m}(x)\mathrm{e}^{\lambda x}\ \Longrightarrow\ y^{*}=x^{k}Q_{m}(x)\mathrm{e}^{\lambda x},$$

$$f(x)=\mathrm{e}^{\alpha x}\left[P_{l}(x)\cos\beta x+Q_{n}(x)\sin\beta x\right]\ \Longrightarrow\ y^{*}=x^{k}\mathrm{e}^{\alpha x}\left[R_{m}(x)\cos\beta x+T_{m}(x)\sin\beta x\right],$$

其中 $Q_{m},R_{m},T_{m}$ 为待定的 $m$ 次多项式，$m=\max\{l,n\}$。

- $k$ 是 $\lambda$（或 $\alpha\pm\mathrm{i}\beta$）作为特征根的重数：不是特征根取 $k=0$，单根或单重复根取 $k=1$，二重根取 $k=2$。
- 自由项只含 $\cos\beta x$ 或 $\sin\beta x$ 时，先解自由项为 $P_{m}(x)\mathrm{e}^{(\alpha+\mathrm{i}\beta)x}$ 的方程，再取实部或虚部作特解。
- 待定系数代回后比较同类项即可；$y^{*}$ 只需求出一个，不要再把齐次通解并进去。

依据红书 §4.2 题型二 3：[[数学竞赛/红书/各章节/第4章 常微分方程#3. 二阶常系数线性微分方程的解法]]。

# Euler 方程

$$x^{n}y^{(n)}+a_{1}x^{n-1}y^{(n-1)}+\cdots+a_{n-1}xy'+a_{n}y=f(x)\qquad(a_{1},\dots,a_{n}\text{ 为常数}),$$

作代换 $x=\mathrm{e}^{t}$（即 $t=\ln x$，$x>0$），记 $\mathrm{D}=\dfrac{\mathrm{d}}{\mathrm{d}t}$，则

$$x^{k}y^{(k)}=\mathrm{D}(\mathrm{D}-1)(\mathrm{D}-2)\cdots(\mathrm{D}-k+1)y,$$

化为以 $t$ 为自变量的常系数线性方程，解出后把 $t$ 换回 $\ln x$。

- 最常用的两条是 $xy'=\mathrm{D}y$、$x^{2}y''=\mathrm{D}(\mathrm{D}-1)y=\mathrm{D}^{2}y-\mathrm{D}y$。
- $x<0$ 时作 $x=-\mathrm{e}^{t}$（$t=\ln(-x)$），否则 $\ln x$ 无意义；也可把结果中的 $x$ 换成 $|x|$。
- 齐次 Euler 方程也可直接令 $y=x^{r}$ 试解，得关于 $r$ 的代数方程；非齐次时仍用代换法降为常系数方程。

依据红书 §4.2 题型二 4：[[数学竞赛/红书/各章节/第4章 常微分方程#4. Euler 方程的解法]]。
