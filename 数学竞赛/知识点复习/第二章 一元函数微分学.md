# 高阶导数求导

**高阶导数定义**：$f^{(n)}(x)=\left(f^{(n-1)}(x)\right)'$。

**莱布尼茨公式**：若 $u,v$ 都有 $n$ 阶导数，则

$$(uv)^{(n)}=\sum_{k=0}^{n}\binom{n}{k}u^{(k)}v^{(n-k)}.$$

**常用 $n$ 阶导数**（$n\geqslant1$）：

| $f(x)$ | $f^{(n)}(x)$ |
|---|---|
| $x^{m}$ | $\dfrac{m!}{(m-n)!}x^{m-n}$（$n\leqslant m$），$n>m$ 时为 $0$ |
| $\mathrm{e}^{ax}$ | $a^{n}\mathrm{e}^{ax}$ |
| $a^{x}$ | $(\ln a)^{n}a^{x}$ |
| $\sin(ax+b)$ | $a^{n}\sin\left(ax+b+\dfrac{n\pi}{2}\right)$ |
| $\cos(ax+b)$ | $a^{n}\cos\left(ax+b+\dfrac{n\pi}{2}\right)$ |
| $\ln(ax+b)$ | $\dfrac{(-1)^{n-1}a^{n}(n-1)!}{(ax+b)^{n}}$ |
| $\dfrac{1}{ax+b}$ | $\dfrac{(-1)^{n}a^{n}n!}{(ax+b)^{n+1}}$ |

- 求法四种：逐次求导后归纳（$\mathrm{e}^{ax}$、$\sin$、$\cos$ 一类）；莱布尼茨公式（一个因子是低次多项式时只取前几项，如 $x^{2}\mathrm{e}^{x}$）；先拆项再用上表（有理式拆部分分式，$\sin^{2}x=\frac{1-\cos2x}{2}$）；先找 $f$ 满足的微分方程再逐次求导得递推（如 $y=\arcsin x$ 时 $(1-x^{2})y''-xy'=0$）。
- $f(x)=\sum\limits_{n=0}^{\infty}\frac{f^{(n)}(0)}{n!}x^{n}$ 给出 $f^{(n)}(0)=n!\,a_{n}$：求某一点的高阶导数时，先展开 Taylor 再取系数，通常比逐次求导快。
- 通项公式只有在各阶导数形式统一后才成立，先写出前 3～4 阶再归纳；分段函数在分界点的高阶导数要用定义逐次验证左右导数。

# 微分中值定理

> **费马引理** 设 $f$ 在 $x_{0}$ 的某邻域内有定义，在 $x_{0}$ 处可导且取到极值，则 $f'(x_{0})=0$。

> **罗尔定理** 设 $f$ 在 $[a,b]$ 上连续、在 $(a,b)$ 内可导，且 $f(a)=f(b)$，则存在 $\xi\in(a,b)$，使 $f'(\xi)=0$。

> **拉格朗日中值定理** 设 $f$ 在 $[a,b]$ 上连续、在 $(a,b)$ 内可导，则存在 $\xi\in(a,b)$，使
> $$f(b)-f(a)=f'(\xi)(b-a).$$

> **柯西中值定理** 设 $f$、$g$ 在 $[a,b]$ 上连续、在 $(a,b)$ 内可导，且 $g'(x)\neq0$，则存在 $\xi\in(a,b)$，使
> $$\frac{f(b)-f(a)}{g(b)-g(a)}=\frac{f'(\xi)}{g'(\xi)}.$$

- 三者是一条链：柯西定理取 $g(x)=x$ 即拉格朗日定理，拉格朗日定理在 $f(a)=f(b)$ 时即罗尔定理；证明顺序反之：费马 → 罗尔（极值点或最值点）→ 拉格朗日（减去弦线函数后对差函数用罗尔）→ 柯西（对参数化的差函数用罗尔）。
- 条件：闭区间连续、开区间可导（端点不要求可导）不可省；柯西定理另需 $g'(x)\neq0$，它保证 $g(b)\neq g(a)$；$\xi$ 只保证存在，不保证唯一，也不能指出具体位置。
- 常用构造：证 $f'(\xi)+k f(\xi)=0$ 时取辅助函数 $\mathrm{e}^{kx}f(x)$；证含 $\frac{f'(\xi)}{g'(\xi)}$ 的等式用柯西定理；出现两个中值点 $\xi$、$\eta$ 时，把它们分别放在两个不同区间上用拉格朗日与柯西定理。

# 渐近线、曲率与曲率圆

## 1. 渐近线

> **垂直渐近线**：若 $\lim\limits_{x\to x_{0}^{+}}f(x)=\infty$ 或 $\lim\limits_{x\to x_{0}^{-}}f(x)=\infty$，则 $x=x_{0}$ 是垂直渐近线；$x_{0}$ 一般出现在分母零点、对数零点或定义域端点。

> **水平渐近线**：若 $\lim\limits_{x\to+\infty}f(x)=b$（或 $x\to-\infty$ 时），则 $y=b$ 是水平渐近线。

> **斜渐近线**：若 $k=\lim\limits_{x\to+\infty}\dfrac{f(x)}{x}$ 存在且 $k\neq0$，$b=\lim\limits_{x\to+\infty}\left(f(x)-kx\right)$ 存在，则 $y=kx+b$ 是斜渐近线；$k=0$ 时退化为水平渐近线。

- 求法顺序：先找使 $f(x)\to\infty$ 的点得到垂直渐近线，再算 $x\to\pm\infty$ 时 $f(x)$ 的极限得到水平渐近线，最后按 $k$、$b$ 的公式求斜渐近线；$x\to+\infty$ 与 $x\to-\infty$ 必须分别计算，两侧可以不同。

## 2. 曲率与曲率半径

> 弧微分 $\mathrm{d}s=\sqrt{1+(y')^{2}}\,\mathrm{d}x$，曲率与曲率半径为
> $$K=\frac{|y''|}{\left[1+(y')^{2}\right]^{3/2}},\qquad R=\frac{1}{K}=\frac{\left[1+(y')^{2}\right]^{3/2}}{|y''|}.$$
> 曲线由参数方程 $x=x(t)$、$y=y(t)$ 给出时
> $$K=\frac{|x'y''-x''y'|}{\left(x'^{2}+y'^{2}\right)^{3/2}}.$$

- 直线的曲率为 $0$、曲率半径为无穷大；$y''=0$ 处曲率圆退化为直线，上述 $R$ 与曲率中心公式不适用。

## 3. 曲率中心

> 曲率圆的圆心 $(\alpha,\beta)$ 为
> $$\alpha=x-\frac{y'\left[1+(y')^{2}\right]}{y''},\qquad\beta=y+\frac{1+(y')^{2}}{y''}.$$
> 参数方程形式为
> $$\alpha=x-\frac{y'\left(x'^{2}+y'^{2}\right)}{x'y''-x''y'},\qquad\beta=y+\frac{x'\left(x'^{2}+y'^{2}\right)}{x'y''-x''y'}.$$

- 曲率圆在该点与曲线相切、曲率相同、凹向相同，因此 $R=\sqrt{(x-\alpha)^{2}+(y-\beta)^{2}}$；圆心总在曲线的凹侧，即 $y''>0$ 时在曲线上方，$y''<0$ 时在曲线下方。
