# 基本积分表

表中 $C$ 为任意常数，$a>0$。

**幂与根式**

| 被积函数 | 原函数 | 条件 |
|---|---|---|
| $x^{a}$ | $\dfrac{x^{a+1}}{a+1}+C$ | $a\neq-1$ |
| $\dfrac{1}{x}$ | $\ln\lvert x\rvert+C$ | $x\neq0$ |
| $\dfrac{1}{a^{2}+x^{2}}$ | $\dfrac{1}{a}\arctan\dfrac{x}{a}+C$ | $a>0$ |
| $\dfrac{1}{x^{2}-a^{2}}$ | $\dfrac{1}{2a}\ln\left\lvert\dfrac{x-a}{x+a}\right\rvert+C$ | $a>0,\ x\neq\pm a$ |
| $\dfrac{1}{a^{2}-x^{2}}$ | $\dfrac{1}{2a}\ln\left\lvert\dfrac{a+x}{a-x}\right\rvert+C$ | $a>0,\ \lvert x\rvert\neq a$ |
| $\dfrac{1}{\sqrt{a^{2}-x^{2}}}$ | $\arcsin\dfrac{x}{a}+C$ | $a>0,\ \lvert x\rvert<a$ |
| $\dfrac{1}{\sqrt{x^{2}\pm a^{2}}}$ | $\ln\left\lvert x+\sqrt{x^{2}\pm a^{2}}\right\rvert+C$ | $a>0$ |
| $\sqrt{a^{2}-x^{2}}$ | $\dfrac{x}{2}\sqrt{a^{2}-x^{2}}+\dfrac{a^{2}}{2}\arcsin\dfrac{x}{a}+C$ | $a>0$ |
| $\sqrt{x^{2}+a^{2}}$ | $\dfrac{x}{2}\sqrt{x^{2}+a^{2}}+\dfrac{a^{2}}{2}\ln\left(x+\sqrt{x^{2}+a^{2}}\right)+C$ | $a>0$ |
| $\sqrt{x^{2}-a^{2}}$ | $\dfrac{x}{2}\sqrt{x^{2}-a^{2}}-\dfrac{a^{2}}{2}\ln\left\lvert x+\sqrt{x^{2}-a^{2}}\right\rvert+C$ | $a>0,\ \lvert x\rvert>a$ |

**指数与对数**

| 被积函数 | 原函数 | 条件 |
|---|---|---|
| $\mathrm{e}^{ax}$ | $\dfrac{1}{a}\mathrm{e}^{ax}+C$ | $a\neq0$ |
| $a^{x}$ | $\dfrac{a^{x}}{\ln a}+C$ | $a>0,\ a\neq1$ |
| $\ln x$ | $x\ln x-x+C$ | $x>0$ |
| $x^{n}\ln x$ | $\dfrac{x^{n+1}}{n+1}\ln x-\dfrac{x^{n+1}}{(n+1)^{2}}+C$ | $n\neq-1$ |
| $\dfrac{1}{x\ln x}$ | $\ln\lvert\ln x\rvert+C$ | $x>0,\ x\neq1$ |

**三角**

| 被积函数 | 原函数 | 条件 |
|---|---|---|
| $\sin ax$ | $-\dfrac{1}{a}\cos ax+C$ | $a\neq0$ |
| $\cos ax$ | $\dfrac{1}{a}\sin ax+C$ | $a\neq0$ |
| $\tan x$ | $-\ln\lvert\cos x\rvert+C$ | |
| $\cot x$ | $\ln\lvert\sin x\rvert+C$ | |
| $\sec x$ | $\ln\lvert\sec x+\tan x\rvert+C$ | |
| $\csc x$ | $\ln\lvert\csc x-\cot x\rvert+C$ | |
| $\sec^{2}x$ | $\tan x+C$ | |
| $\csc^{2}x$ | $-\cot x+C$ | |
| $\sec x\tan x$ | $\sec x+C$ | |
| $\csc x\cot x$ | $-\csc x+C$ | |
| $\sin^{2}x$ | $\dfrac{x}{2}-\dfrac{\sin 2x}{4}+C$ | |
| $\cos^{2}x$ | $\dfrac{x}{2}+\dfrac{\sin 2x}{4}+C$ | |
| $\tan^{2}x$ | $\tan x-x+C$ | |
| $\dfrac{1}{\sin x\cos x}$ | $\ln\lvert\tan x\rvert+C$ | |

**反三角**

| 被积函数 | 原函数 | 条件 |
|---|---|---|
| $\arcsin x$ | $x\arcsin x+\sqrt{1-x^{2}}+C$ | $\lvert x\rvert\leqslant1$ |
| $\arccos x$ | $x\arccos x-\sqrt{1-x^{2}}+C$ | $\lvert x\rvert\leqslant1$ |
| $\arctan x$ | $x\arctan x-\dfrac{1}{2}\ln(1+x^{2})+C$ | |
| $\operatorname{arccot} x$ | $x\operatorname{arccot} x+\dfrac{1}{2}\ln(1+x^{2})+C$ | |

**双曲**

| 被积函数 | 原函数 | 条件 |
|---|---|---|
| $\sinh x$ | $\cosh x+C$ | |
| $\cosh x$ | $\sinh x+C$ | |
| $\tanh x$ | $\ln\cosh x+C$ | |
| $\dfrac{1}{\cosh x}$ | $2\arctan \mathrm{e}^{x}+C$ | |
| $\dfrac{1}{\sinh x}$ | $\ln\left\lvert\tanh\dfrac{x}{2}\right\rvert+C$ | $x\neq0$ |

- 每个原函数都含任意常数 $C$；$\ln$ 内的绝对值、$\arctan$ 前的系数 $\frac{1}{a}$、$\arcsin$ 中的 $\frac{x}{a}$ 最易漏写。
- 含参数 $a$ 的公式由 $x=at$ 化归 $a=1$ 的情形，记表时只需记 $a=1$ 一行。

# 常用积分代换

| 被积式特征 | 代换 | 作用 |
|---|---|---|
| $\sqrt{a^{2}-x^{2}}$ | $x=a\sin t$ | 用 $1-\sin^{2}t=\cos^{2}t$ 去根号 |
| $\sqrt{a^{2}+x^{2}}$ | $x=a\tan t$ | 用 $1+\tan^{2}t=\sec^{2}t$ 去根号 |
| $\sqrt{x^{2}-a^{2}}$ | $x=a\sec t$ | 用 $\sec^{2}t-1=\tan^{2}t$ 去根号 |
| $R(\sin x,\cos x)$ | $t=\tan\dfrac{x}{2}$ | 化为 $t$ 的有理函数 |
| $\sqrt[n]{ax+b}$ | $t=\sqrt[n]{ax+b}$ | 去根号 |
| $R(\mathrm{e}^{x})$ | $t=\mathrm{e}^{x}$ | 化为有理函数 |

万能代换下

$$\sin x=\frac{2t}{1+t^{2}},\qquad\cos x=\frac{1-t^{2}}{1+t^{2}},\qquad\mathrm{d}x=\frac{2\,\mathrm{d}t}{1+t^{2}}.$$

- 万能代换必定成功但计算量最大，能用凑微分或三角恒等变形时不用它。
- 根式代换后开方取正或取负，由 $t$ 所在区间决定。
- 定积分换元要同时换上下限，换元后不回代。

# 常用递推公式

$$\int\sin^{n}x\,\mathrm{d}x=-\frac{\sin^{n-1}x\cos x}{n}+\frac{n-1}{n}\int\sin^{n-2}x\,\mathrm{d}x,$$

$$\int\cos^{n}x\,\mathrm{d}x=\frac{\cos^{n-1}x\sin x}{n}+\frac{n-1}{n}\int\cos^{n-2}x\,\mathrm{d}x,$$

$$\int\tan^{n}x\,\mathrm{d}x=\frac{\tan^{n-1}x}{n-1}-\int\tan^{n-2}x\,\mathrm{d}x,$$

$$\int\frac{\mathrm{d}x}{(x^{2}+a^{2})^{n}}=\frac{x}{2a^{2}(n-1)(x^{2}+a^{2})^{n-1}}+\frac{2n-3}{2a^{2}(n-1)}\int\frac{\mathrm{d}x}{(x^{2}+a^{2})^{n-1}},$$

$$\int x^{n}\mathrm{e}^{ax}\,\mathrm{d}x=\frac{x^{n}\mathrm{e}^{ax}}{a}-\frac{n}{a}\int x^{n-1}\mathrm{e}^{ax}\,\mathrm{d}x,$$

$$\int(\ln x)^{n}\,\mathrm{d}x=x(\ln x)^{n}-n\int(\ln x)^{n-1}\,\mathrm{d}x.$$

- 每一步把下标降低 $1$ 或 $2$，最终归到基本积分，系数中的 $n$ 全程保持不变。
- 下标为 $0,1$ 的初值要单独给出，否则递推无法启动。

# 定积分常用公式

$$\int_{-a}^{a}f(x)\,\mathrm{d}x=\begin{cases}0, & f\text{ 为奇函数},\\ 2\int_{0}^{a}f(x)\,\mathrm{d}x, & f\text{ 为偶函数},\end{cases}$$

$$\int_{a}^{a+T}f(x)\,\mathrm{d}x=\int_{0}^{T}f(x)\,\mathrm{d}x\qquad(f\text{ 以 }T\text{ 为周期}),$$

$$\int_{0}^{a}f(x)\,\mathrm{d}x=\int_{0}^{a}f(a-x)\,\mathrm{d}x,$$

$$\int_{0}^{\pi}x f(\sin x)\,\mathrm{d}x=\frac{\pi}{2}\int_{0}^{\pi}f(\sin x)\,\mathrm{d}x,$$

$$\int_{0}^{\pi/2}\sin^{n}x\,\mathrm{d}x=\int_{0}^{\pi/2}\cos^{n}x\,\mathrm{d}x=\begin{cases}\dfrac{(n-1)!!}{n!!}\cdot\dfrac{\pi}{2}, & n\text{ 为偶数},\\ \dfrac{(n-1)!!}{n!!}, & n\text{ 为奇数}.\end{cases}$$

- 偶数情形以 $\frac{\pi}{2}$ 收尾、奇数情形以 $1$ 收尾，$n=0$ 时约定 $(-1)!!=1$。
- 周期函数在任意一个周期长度的区间上积分相等，因此可以平移积分区间。
- 区间再现公式把 $x$ 与 $a-x$ 配对，是消去被积式中 $x$ 因子的主要手段。

# 变上限积分

$$\frac{\mathrm{d}}{\mathrm{d}x}\int_{\psi(x)}^{\varphi(x)}f(t)\,\mathrm{d}t=f\bigl(\varphi(x)\bigr)\varphi'(x)-f\bigl(\psi(x)\bigr)\psi'(x).$$

- 被积函数含 $x$ 时，先换元把 $x$ 移入上限或提出，再求导。
- $f$ 连续时变上限积分可导且导数为 $f$；$f$ 仅可积时变上限积分连续，未必可导。

# 反常积分常用值

$$\int_{0}^{+\infty}\mathrm{e}^{-ax}\,\mathrm{d}x=\frac{1}{a}\quad(a>0),\qquad\int_{0}^{+\infty}\mathrm{e}^{-x^{2}}\,\mathrm{d}x=\frac{\sqrt{\pi}}{2},$$

$$\Gamma(s)=\int_{0}^{+\infty}x^{s-1}\mathrm{e}^{-x}\,\mathrm{d}x,\qquad\Gamma(n+1)=n!,\qquad\Gamma\left(\frac{1}{2}\right)=\sqrt{\pi},$$

$$\mathrm{B}(p,q)=\int_{0}^{1}x^{p-1}(1-x)^{q-1}\,\mathrm{d}x=\frac{\Gamma(p)\Gamma(q)}{\Gamma(p+q)},$$

$$\int_{0}^{\pi/2}\sin^{2p-1}x\cos^{2q-1}x\,\mathrm{d}x=\frac{1}{2}\mathrm{B}(p,q),$$

$$\int_{0}^{+\infty}\frac{\sin x}{x}\,\mathrm{d}x=\frac{\pi}{2},\qquad\int_{0}^{\pi/2}\ln\sin x\,\mathrm{d}x=-\frac{\pi}{2}\ln2,$$

$$\int_{0}^{+\infty}\frac{x^{a-1}}{1+x}\,\mathrm{d}x=\frac{\pi}{\sin a\pi}\quad(0<a<1).$$

- 积分区间无界或被积函数无界都属于反常积分，先判敛散再求值。
- 判敛以 $p$ 积分为标准：$\int_{1}^{+\infty}\frac{\mathrm{d}x}{x^{p}}$ 收敛当且仅当 $p>1$，$\int_{0}^{1}\frac{\mathrm{d}x}{x^{p}}$ 收敛当且仅当 $p<1$。
