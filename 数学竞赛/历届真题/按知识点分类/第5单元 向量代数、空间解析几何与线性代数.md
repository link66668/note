(3) 设  $A = \left( \begin{array}{ccc} \lambda & 0 & 0 \\ 0 & \lambda & 0 \\ -1 & 1 & \lambda \end{array} \right)$，则  $A^{50} =$ ___.

> [!answer]- 参考答案（原书 OCR，待核验）
> (3) 记  $B = \left( \begin{array}{ccc} 0 & 0 & 0 \\ 0 & 0 & 0 \\ -1 & 1 & 0 \end{array} \right)$，则  $A = \lambda E + B, B^{2} = O$，所以
>
> $$\boldsymbol{A}^{50}=(\lambda\boldsymbol{E}+\boldsymbol{B})^{50}=\lambda^{50}\boldsymbol{E}+50\lambda^{49}\boldsymbol{B}=\left(\begin{array}{c c c}{\lambda^{50}}&{0}&{0}\\ {0}&{\lambda^{50}}&{0}\\ {-50\lambda^{49}}&{50\lambda^{49}}&{\lambda^{50}}\end{array}\right).$$

**2. [[数学竞赛/历届真题/第07届非数学专业类决赛.md#决赛试题与解析|第7届决赛·第一题（4）]]** ^unit-final-07-1-sub4

（4）设  $\lambda_{1},\lambda_{2},\cdots,\lambda_{n}$ 是 n 阶方阵 A 的特征值， $f(x)$ 是多项式，则矩阵  $f(A)$ 的行列式的值为 ___.

> [!answer]- 参考答案（原书 OCR，待核验）
> (4) 因为  $\lambda_{i}$ 是 A 的特征值，所以  $f(\lambda_{i})$ 是  $f(A)$ 的特征值， $i=1,2,\cdots,n$ 。因此
>
> $$\left|A\right|=f(\lambda_{1})f(\lambda_{2})\cdots f(\lambda_{n}).$$

**3. [[数学竞赛/历届真题/第08届非数学专业类决赛.md#决赛试题与解析|第8届决赛·第一题（3）]]** ^unit-final-08-1-sub3

（6 分）

(3) 已知 A 为 n 阶可逆反对称矩阵，b 为 n 元列向量，设  $B = \left( \begin{array}{cc} A & b \\ b^{\mathrm{T}} & 0 \end{array} \right)$，则  $\mathrm{rank}(B) =$ ___.

> [!answer]- 参考答案（原书 OCR，待核验）
> (3) 因为  $A^{T} = -A$，所以  $(A^{-1})^{\mathrm{T}} = (A^{\mathrm{T}})^{-1} = (-A)^{-1} = -A^{-1}$，即  $A^{-1}$ 也是反对称矩阵，故对任意 n 维列向量 b，都有  $b^{T}A^{-1}b = 0$。对矩阵 B 施行分块初等变换，得
>
> $$\boldsymbol{B}=\left(\begin{array}{c c}{\boldsymbol{A}}&{\boldsymbol{b}}\\ {\boldsymbol{b}^{\mathrm{T}}}&{0}\\ \end{array}\right)\rightarrow\left(\begin{array}{c c}{\boldsymbol{A}}&{0}\\ {0}&{-\boldsymbol{b}^{\mathrm{T}}\boldsymbol{A}^{-1}\boldsymbol{b}}\\ \end{array}\right)=\left(\begin{array}{c c}{\boldsymbol{A}}&{0}\\ {0}&{0}\\ \end{array}\right),$$
>
> 因此， $\operatorname{rank}(B) = \operatorname{rank}(A) = n$.

$c^{z}=dab,d^{w}=abc$, 则行列式  $\left|\begin{array}{cccc}-x&1&1&1\\1&-y&1&1\\1&1&-z&1\\1&1&1&-w\end{array}\right|=$ ___.

>
> $$\left\{\begin{array}{l}-x\ln a+\ln b+\ln c+\ln d=0,\\\\\ln a-y\ln b+\ln c+\ln d=0,\\\\\ln a+\ln b-z\ln c+\ln d=0,\\\\\ln a+\ln b+\ln c-w\ln d=0.\end{array}\right.$$

>
> $$\left|\begin{array}{c c c c}{{{-x}}}&{{{1}}}&{{{1}}}&{{{1}}} \\{{{1}}}&{{{-y}}}&{{{1}}}&{{{1}}} \\{{{1}}}&{{{1}}}&{{{-z}}}&{{{1}}} \\{{{1}}}&{{{1}}}&{{{1}}}&{{{-w}}}\end{array}\right|=0.$$

(5) 已知二次型  $f(x_{1}, x_{2}, \cdots, x_{n}) = \sum_{i=1}^{n} \left( x_{i} - \frac{x_{1} + x_{2} + \cdots + x_{n}}{n} \right)^{2}$，则 f 的规范形为 ___.

> [!answer]- 参考答案（原书 OCR，待核验）

>

> [!answer]- 参考答案（原书 OCR，待核验）
> 一、[参考解析] （1）利用条件： $|b|=1$， $\langle a,b\rangle=\frac{\pi}{4}$，得  $a\cdot b=|a||b|\cos\langle a,b\rangle=\frac{\sqrt{2}}{2}|a|$，所以
>

>
> 因此
>
>  $$\begin{aligned}\lim_{x\to0}\frac{|a+xb|-|a|}{x}&=\lim_{x\to0}\frac{\sqrt{a^{2}+\sqrt{2}x|a|+x^{2}}-|a|}{x}\\&=\lim_{x\to0}\frac{\sqrt{2}|a|+x}{\sqrt{a^{2}+\sqrt{2}x|a|+x^{2}}+|a|}=\frac{\sqrt{2}}{2}.\end{aligned}$$

>
>  $$\begin{array}{r}{B^{2021}=(Q D^{\frac{1}{2021}}Q^{\mathrm{T}})^{2021}=Q D Q^{\mathrm{T}}=A,}\end{array}$$
>
> 且满足
>
>  $$AB=QDQ^{\mathrm{T}}QD^{\frac{1}{2021}}Q^{\mathrm{T}}=QDD^{\frac{1}{2021}}Q^{\mathrm{T}}=QD^{\frac{1}{2021}}DQ^{\mathrm{T}}=QD^{\frac{1}{2021}}Q^{\mathrm{T}}QDQ^{\mathrm{T}}=BA.$$
>
> (2) 设  $\lambda_{1}, \lambda_{2}, \cdots, \lambda_{s}$ 是两两互异的  $(s \leqslant n)$，利用待定系数法，存在唯一的 s 次多项式  $p(x)$，使得  $p(\lambda_{i}) = \lambda_{i}^{\frac{1}{2021}}$ (i = 1, 2,  $\cdots$, s). 因为  $p(D) = D^{\frac{1}{2021}}$，所以
>
>  $$p(A)=p(Q D Q^{\mathrm{T}})=Q p(D)Q^{\mathrm{T}}=Q D^{\frac{1}{2021}}Q^{\mathrm{T}}=B.$$
>
> （3）设另存在 n 阶实对称矩阵 C 使得  $C^{2021} = A$，则  $B = p(A) = p(C^{2021})$，所以  $BC = p(C^{2021})C = Cp(C^{2021}) = CB$。由于 B, C 都可相似对角化，故存在 n 阶可逆实矩阵 C 及实对角矩阵  $D_{1}, D_{2}$，使得  $B = TD_{1}T^{-1}, C = TD_{2}T^{-1}$。因此  $C^{2021} = A = B^{2021} \Rightarrow D_{2}^{2021} = D_{1}^{2021} \Rightarrow D_{2} = D_{1} \Rightarrow C = B$，唯一性得证。

**14. [[数学竞赛/历届真题/第13届非数学专业类决赛.md#决赛试题与解析|第13届决赛·第七题]]** ^unit-final-13-7

七、（本题 12 分） 设  $A = (a_{ij})$ 为 n 阶实矩阵,  $\alpha_{1}, \alpha_{2}, \cdots, \alpha_{n}$ 为 A 的 n 个列向量, 且均不为零. 证明: 矩阵 A 的秩满足

 $$r(A)\geqslant\sum_{i=1}^{n}\frac{a_{ii}^{2}}{\alpha_{i}^{\mathrm{T}}\alpha_{i}}.$$

> [!answer]- 参考答案（原书 OCR，待核验）
> 七、[参考证明] 注意到用非零常数乘矩阵的列向量不改变矩阵的秩  $r(A)$，故可设  $\alpha_{i}^{T}\alpha_{i}=1, i=1,2,\cdots,n$，所以只需证明
>
>  $$r(\boldsymbol{A})\geqslant\sum_{i=1}^{n}a_{i i}^{2},\quad r(\boldsymbol{A})\geqslant\sum_{i=1}^{n}(e_{i}^{\mathrm{T}}\alpha_{i})^{2}.$$
>
> 其中  $\boldsymbol{e}_{i} = (0, \cdots, 0, 1, 0, \cdots, 0)^{\mathrm{T}}$ 是第 i 个分量为 1 其余分量均为 0 的 n 维列向量.
>
> 令  $r(A)=k$，则由  $\alpha_{1},\alpha_{2},\cdots,\alpha_{n}$ 的任一极大无关组并利用 Schmidt（施密特）正交化方法，可得标准正交向量组  $\beta_{1},\beta_{2},\cdots,\beta_{k}$。易知，向量组  $\alpha_{1},\alpha_{2},\cdots,\alpha_{n}$ 与  $\beta_{1},\beta_{2},\cdots,\beta_{k}$ 等价。
>
> 对任意  $i = 1,2,\cdots,n$，令  $\alpha_{i} = \sum_{j=1}^{k} x_{j} \beta_{j}$，则由  $\beta_{1}, \beta_{2}, \cdots, \beta_{k}$ 的标准正交性可知， $x_{j} = \beta_{j}^{T} \alpha_{i}, j = 1,2,\cdots,k$，所以  $\alpha_{i} = \sum_{j=1}^{k} (\beta_{j}^{T} \alpha_{i}) \beta_{j}$，于是  $e_{i}^{T} \alpha_{i} = \sum_{j=1}^{k} (\beta_{j}^{T} \alpha_{i}) (e_{i}^{T} \beta_{j})$.
>
> 根据 Cauchy-Schwarz（柯西-施瓦茨）不等式，并注意到  $\sum_{j=1}^{k}(\beta_{j}^{\mathrm{T}}\alpha_{i})^{2}=\alpha_{i}^{\mathrm{T}}\alpha_{i}=1$
>
> 可得
>
>  $$\begin{align*}(e_{i}^{\mathrm{T}}\alpha_{i})^{2}&=\left(\sum_{j=1}^{k}(\beta_{j}^{\mathrm{T}}\alpha_{i})(e_{i}^{\mathrm{T}}\beta_{j})\right)^{2}\leqslant\sum_{j=1}^{k}(\beta_{j}^{\mathrm{T}}\alpha_{i})^{2}\sum_{j=1}^{k}(e_{i}^{\mathrm{T}}\beta_{j})^{2}=\sum_{j=1}^{k}(e_{i}^{\mathrm{T}}\beta_{j})^{2},\\&\sum_{i=1}^{n}(e_{i}^{\mathrm{T}}\alpha_{i})^{2}\leqslant\sum_{j=1}^{k}\sum_{i=1}^{n}(e_{i}^{\mathrm{T}}\beta_{j})^{2}=\sum_{j=1}^{k}(\beta_{j}^{\mathrm{T}}\beta_{j})^{2}=k=r(A).\end{align*}$$

**15. [[数学竞赛/历届真题/第14届非数学专业类决赛.md#决赛试题与解析|第14届决赛·第二题]]** ^unit-final-14-2

**二、**（本题10分）用正交变换将二次曲面的方程

 $$x^{2}-2y^{2}-2z^{2}-4xy+4xz+8yz-27=0$$

化为标准方程，并说明该曲面是什么曲面.

> [!answer]- 参考答案（原书 OCR，待核验）
> 二、[参考解析] 设  $A = \left( \begin{array}{ccc} 1 & -2 & 2 \\ -2 & -2 & 4 \\ 2 & 4 & -2 \end{array} \right)$,  $\boldsymbol{x} = (x, y, z)^{\mathrm{T}}$，则曲面方程为
>
>  $$x^{\mathrm{T}}A x=27.$$
>
> 易知，A 的特征多项式为  $\left|\lambda\boldsymbol{E}-\boldsymbol{A}\right|=\left|\begin{array}{ccc}\lambda-1&2&-2\\2&\lambda+2&-4\\-2&-4&\lambda+2\end{array}\right|=(\lambda-2)^{2}(\lambda+7)$，所以 A 的特征值为  $\lambda_{1}=2$（二重）， $\lambda_{2}=-7$.
>
> 对于  $\lambda_{1}=2$，解齐次线性方程组  $(\lambda_{1}E-A)x=0$，求得对应的线性无关的特征向量为  $\alpha_{1}=(-2,1,0)^{\mathrm{T}},\alpha_{2}=(2,0,1)^{\mathrm{T}}$，利用 Schmidt 正交化方法，得
>
>  $$\boldsymbol{\beta}_{1}=\frac{1}{\sqrt{5}}(-2,1,0)^{\mathrm{T}},\quad\boldsymbol{\beta}_{2}=\frac{1}{3\sqrt{5}}(2,4,5)^{\mathrm{T}}.$$
>
> 对于  $\lambda_{2}=-7$，解齐次线性方程组  $(\lambda_{2}E-A)x=0$，求得对应的单位化特征向量为  $\beta_{3}=\frac{1}{3}(1,2,-2)^{\mathrm{T}}$.
>
> 取正交矩阵  $Q = (\beta_{1}, \beta_{2}, \beta_{3})$，令  $\boldsymbol{x}^{\prime} = (x^{\prime}, y^{\prime}, z^{\prime})^{\mathrm{T}}$，则正交变换 x = Qx' 将曲面的方程  $x^{T}Ax = 27$ 可化为如下标准方程：
>
>  $$2x^{\prime2}+2y^{\prime2}-7z^{\prime2}=27.$$
>
> 这是单叶双曲面.

**16. [[数学竞赛/历届真题/第15届非数学专业类决赛.md#决赛试题与解析|第15届决赛·第五题]]** ^unit-final-15-5

五、（本题12分）设 n 阶实矩阵 A, B 满足 AB = A + B，且存在 n 阶可逆实矩阵 P，使得  $P^{-1}AP$ 为对角矩阵. 证明： $P^{-1}BP$ 也为对角矩阵.
> [!answer]- 参考答案（原书 OCR，待核验）
> 五、[参考解析] 设  $P^{-1}AP = \mathrm{diag}(\lambda_{1},\lambda_{2},\cdots,\lambda_{n})$，且  $P = (p_{1}, p_{2}, \cdots, p_{n})$，则  $Ap_{i} = \lambda_{i}p_{i}, i = 1,2,\cdots,n$。所以 P 的列向量  $p_{i} (i = 1,2,\cdots,n)$ 为 A 的对应于特征值  $\lambda_{i}$ 的特征向量。
>
> 因为 AB = A + B，所以  $(A - E)(B - E) = E$，可知  $\left|A - E\right| \neq 0$，由此说明  $\lambda_{i} \neq 1$。
>
> 注意到  $(A-E)p_{i}=(\lambda_{i}-1)p_{i}$，所以  $(A-E)^{-1}p_{i}=\frac{1}{\lambda_{i}-1}p_{i}$。又由于
>
>  $$ABp_{i}=Ap_{i}+Bp_{i}=\lambda_{i}p_{i}+Bp_{i},$$
>
> 所以  $Bp_{i}=\lambda_{i}(A-I)^{-1}p_{i}=\frac{\lambda_{i}}{\lambda_{i}-1}p_{i}$，即  $p_{i}$ 是 B 的属于特征值  $\frac{\lambda_{i}}{\lambda_{i}-1}$ 的特征向量. 因此
>
>  $$P^{-1}BP=\mathrm{diag}\left(\frac{\lambda_{1}}{\lambda_{1}-1},\frac{\lambda_{2}}{\lambda_{2}-1},\cdots,\frac{\lambda_{n}}{\lambda_{n}-1}\right).$$
