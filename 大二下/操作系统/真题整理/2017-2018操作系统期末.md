## 二、填空题

> 共 36 分，每空 2 分。

1. 在引入了程序间的并发功能后，由于它们共享系统资源，并发执行程序带来了间断性、**失去封闭性**和**不可再现性**新特征。
2. 操作系统需要把大量的数据从网卡传递给应用程序，在网卡进程和应用程序进程之间，采用的进程通信方式是：**共享存储器系统**。
3. 请求分页存储管理中“最近最久未用 LRU”页面置换算法为了记录使用时间和最近使用情况，常采用**寄存器**和**栈**实现。
4. 1968 年，科学家 Denning 指出程序在执行时将呈现出**局部性**规律，促进了虚拟存储研究工作的开展。
5. 1965 年，荷兰学者 Dijkstra 提出的**信号量**机制是一种卓有成效的进程同步工具。
6. Denning 于 1980 年提出了“$L=S$”准则来调节多道程序的工作集，其中，$L$ 是**缺页之间的平均时间**，$S$ 是**平均缺页服务时间**。
7. 进程在运行的过程中可能会发生死锁，产生死锁的必要条件有四种：**不可抢占条件、互斥条件、请求和保持条件、循环等待条件**。
8. 为了避免延迟造成严重后果，实时操作系统的主要目标有**截止时间的保证、可预测性**。
9. 时间片大小对系统性能影响很大，一个较为可取的时间片大小是**略大于一次典型的交互所需要的时间**，使大多数交互式进程能够在一个时间片内完成。
10. 进程调度算法中采用了优先级调度算法，其中，“优先级”的类型有**静态**和**动态**两种。
11. 目前信号量的类型有整型信号量、**AND 型信号量**和**信号量集**三种。

## 五、问答题

> 共 28 分，每题 7 分。

### 1. 用户级线程的优点

与进程、内核支持线程相比，用户级线程的主要优点有哪些？请写出 3 种优点。

**原卷答案：**

1. 线程切换不需要转换到内核空间。（2 分）
2. 调度算法可以是进程专用的。（2 分）
3. 用户级线程的实现与 OS 平台无关。（3 分）

### 2. 优先级倒置

请写出可以解决进程“优先级倒置”现象的 2 种方法。

**原卷答案：**

1. 假如进程在进入临界区后，所占用的处理机不允许被抢占。（3 分）
2. 采用动态优先级继承策略。（4 分）

### 3. 银行家算法

若系统中有两种资源 $A$、$B$，Allocation 为已分配资源数，Need 为需求资源数，Available 为空闲资源，资源状态如下：

| 进程 | Allocation $(A,B)$ | Need $(A,B)$ | Available $(A,B)$ |
|---|---|---|---|
| P0 | $(6,3)$ | $(6,2)$ | $(5,5)$ |
| P1 | $(5,8)$ | $(3,7)$ |  |
| P2 | $(18,3)$ | $(6,6)$ |  |
| P3 | $(9,3)$ | $(4,5)$ |  |
| P4 | $(8,7)$ | $(8,8)$ |  |
| P5 | $(9,8)$ | $(7,6)$ |  |

采用银行家算法判断该状态是否安全，要求写出计算步骤并给出确定答案。

| 顺序 | 进程 | Allocation $(A,B)$ | Need $(A,B)$ | 进程完成后的 Available $(A,B)$ |
|---|---|---|---|---|
| 1 | P3 | $(9,3)$ | $(4,5)$ | $(14,8)$ |
| 2 | P4 | $(8,7)$ | $(8,8)$ | $(22,15)$ |
| 3 | P5 | $(9,8)$ | $(7,6)$ | $(31,23)$ |
| 4 | P0 | $(6,3)$ | $(6,2)$ | $(37,26)$ |
| 5 | P1 | $(5,8)$ | $(3,7)$ | $(42,34)$ |
| 6 | P2 | $(18,3)$ | $(6,6)$ | $(60,37)$ |

> **原卷结论：安全序列为 $langle P3,P4,P5,P0,P1,P2\rangle$，系统处于安全状态。**

### 4. 信号量互斥

$p$ 和 $q$ 为同一个程序的两个进程，共享资源 $m$。采用信号量写出两个进程互斥访问临界资源 $m$ 的临界区语句；访问函数用 `access(m)` 表示。

```text
semaphore s = 1

p() {
  wait(s)
  access(m)
  signal(s)
}

q() {
  wait(s)
  access(m)
  signal(s)
}
```

**算法说明：**信号量 $s$ 初值为 1，表示临界资源当前可用。进程进入临界区前执行 `wait(s)`；离开时执行 `signal(s)`。任一时刻最多只有一个进程能通过 `wait(s)`，因此实现对 $m$ 的互斥访问。
