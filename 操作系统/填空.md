

# 操作系统《填空题必背》复习清单

以下内容基于知识库中的历年真题与重点知识点总结整理，覆盖选择/填空/判断题考察范围（除9、10、11章外的各章基本概念）。标注了答案出处。


## 一、操作系统引论（第1章）

- 操作系统是配置在计算机硬件上的**第一层软件**，是对硬件系统的**首次扩充**。[cite:5f1f458f-1]
- 操作系统的目标：**有效性、方便性、可扩充性、开放性**。[cite:5f1f458f-1]
- 操作系统基本特征（四个）：**并发性、共享性、虚拟性、异步性**，其中最重要的是**并发性**。[cite:5f1f458f-1]
- 操作系统主要功能：**处理机管理、存储器管理、设备管理、文件管理、用户接口**。[cite:5f1f458f-1]
- 批处理系统特征：**脱机、多道、成批处理**。[cite:5f1f458f-1]
- 分时系统特征：**多路性、独立性、及时性、交互性**。[cite:5f1f458f-1]
- 现代操作系统由**中断**驱动（interrupt）[cite:e6c024ba-1]。
- 应用程序通过**系统调用**（system calls）获取 OS 提供的服务。[cite:e6c024ba-1]
- 向 OS 传递参数的三种方法：**寄存器（registers）、内存块（memory block）、栈（stack）**。[cite:e6c024ba-1]
- CPU 执行操作系统指令时处于**核心态/内核态（kernel/system/supervisor/privileged）**模式。[cite:e6c024ba-1]

## 二、进程的描述与控制（第2章）

- 并发执行程序带来的新特征：**间断性、失去封闭性、不可再现性**。[cite:e6c2440f-1]
- 进程的特征：**动态性、并发性、独立性、异步性**。[cite:5f1f458f-1]
- 进程的三种基本状态：**就绪、执行、阻塞**；状态转换关系：就绪—(进程调度)→执行—(I/O请求)→阻塞—(I/O完成)→就绪；执行—(时间片用完)→就绪。[cite:5f1f458f-1]
- "走走停停"的特征称为进程的**异步性（异步特征）**。[cite:b33bd74b-1]
- 网卡进程与应用进程之间采用的进程通信方式：**共享存储器系统**。[cite:e6c2440f-1]
- 进程通信的两种方法：**共享内存（shared memory）**和**消息传递（message passing）**。[cite:e6c024ba-1]
- 无可断性...进程调度算法中"优先级"类型有**静态**和**动态**两种。[cite:e6c2440f-1]
- 用户级线程（无需内核支持的线程）称……（出自2020-2021期末，线程实现方式）[cite:2a65e382-12]

## 三、进程同步（第4章）

- 1965年 Dijkstra 提出的**信号量**机制是卓有成效的进程同步工具。[cite:e6c2440f-1]
- 利用信号量实现进程互斥时，应将临界区置于 **wait（P操作）** 和 **signal（V操作）** 之间。[cite:b33bd74b-1]
- 信号量的三种类型：整型信号量、**AND型信号量**、**信号量集**。[cite:e6c2440f-1]
- 信号量的操作：初始化、wait()、**signal()**。[cite:e6c024ba-1]
- 临界区问题的三个好解法条件：**互斥（Mutual Exclusion）、进展（Progress）、有限等待（bounded waiting）**。[cite:e6c024ba-1]
- 临界区指**代码段（a code segment，访问临界资源的那段代码）**。[cite:e6c024ba-1]

## 四、处理机调度与死锁（第3章）

- 产生死锁的必要条件有四种：**互斥条件、请求和保持条件（占有并等待）、不可抢占条件（不剥夺）、循环等待条件（环路等待）**，其中**无法破坏的是互斥条件**。[cite:e6c2440f-1][cite:b33bd74b-1]
- 死锁的处理方法：**预防死锁、避免死锁、检测死锁、解除死锁**。[cite:5f1f458f-1]
- 时间片大小的可取值是**略大于一次典型交互所需要的时间**。[cite:e6c2440f-1]
- 实时操作系统的主要目标：**截止时间的保证、可预测性**。[cite:e6c2440f-1]
- 高优先级进程被低优先级进程延迟/阻塞产生**优先级倒置（inversion）**现象。[cite:2a65e382-12]
- 调度算法中"优先级"的类型有**静态**和**动态**两种。[cite:e6c2440f-1]

## 五、存储器管理 / 虚拟存储器（第5、6章）

- 采用可重定位装入方式，若地址变换在进程装入时一次完成且以后不再改变，称为**静态重定位**。[cite:2a65e382-12]
- 请求分页存储管理"最近最久未用LRU"置换算法常用**寄存器**和**栈**实现。[cite:e6c2440f-1]
- 1968年 Denning 指出程序执行时呈现**局部性**规律，促进虚拟存储研究。[cite:e6c2440f-1]
- 1968...（L=S准则）Denning 于1980年提出"L=S"准则，L是**缺页之间的平均时间**，S是**平均缺页服务时间**。[cite:e6c2440f-1]
- 分页/分段填空：分段存储管理中的段地址是**二维地址**。（判断/填空）[cite:e6c2440f-1]

## 六、输入输出系统（第7章）

- 常用 I/O 控制方式：**程序直接控制方式、中断控制方式、DMA方式、通道方式**。[cite:5f1f458f-1]
- 设备（controller）负责在其控制的外设与本地缓冲存储之间移动数据（device controller）。[cite:e6c024ba-1]
- 引入缓冲区的原因（三条）：缓和 CPU 与 I/O 设备速度不匹配；减少对 CPU 的中断频率、放宽中断响应时间限制；提高 CPU 与 I/O 设备之间的并行性。[cite:5f1f458f-1]

## 二、进程的描述与控制（第2章）

1. 引入程序间并发功能后，并发执行程序带来的新特征：**间断性、失去封闭性、不可再现性**。[cite:e6c2440f-1]
2. 进程的特征：**动态性、并发性、独立性、异步性**。[cite:5f1f458f-1]
3. 进程的三种基本状态：**就绪、执行、阻塞**。
   - 就绪——(进程调度)→执行——(时间片用完)→就绪
   - 执行——(I/O请求)→阻塞——(I/O完成)→就绪 [cite:5f1f458f-1]
4. 进程执行"走走停停"，这种特征称为进程的**异步性**。[cite:5f1f458f-1]
5. 线程的两种实现方式中，无需内核支持的线程称为**用户级线程**（在用户空间实现）。[cite:2a65e382-12]
6. 网卡进程与应用进程之间采用的进程通信方式是**共享存储器系统**。[cite:e6c2440f-1]
7. 进程通信的两种方法：**共享内存（shared memory）**与**消息传递（message passing）**。[cite:e6c024ba-1]
