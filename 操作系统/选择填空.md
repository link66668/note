# 操作系统「选择填空」必背知识点

> 依据知识库整理。根据《考题范围》，选择/填空/判断题占 **50分**，考察 **除第9/10/11章外** 的内容（基本概念 + 少量计算）。[cite:956b9992-1]

## 一、操作系统基本概念（必考）

1. **什么是操作系统**：操作系统是配置在计算机硬件上的**第一层软件**，是对硬件系统的**首次扩充**。[cite:ac9c1640-6]
2. **操作系统的四大目标**：有效性、方便性、可扩充性、开放性。[cite:ac9c1640-6]
3. **操作系统基本特征**：并发性、共享性、虚拟性、异步性。**最重要的特征是并发性**。[cite:ac9c1640-6]
4. **操作系统的主要功能**：处理机管理、存储器管理、设备管理、文件管理、用户接口。[cite:ac9c1640-6]
5. **操作系统的作用**：OS 作为用户与计算机硬件之间的接口、作为系统资源的**管理者**、实现资源的**抽象**。[cite:ac9c1640-6]
6. 多道程序的**道数（degree）**指**内存中的进程数**（判断常考）。[cite:8a4eaa16-6]

## 二、系统分类特征（判断/填空高频）

- **批处理系统特征**：脱机、多道、成批处理。[cite:ac9c1640-6]
- **分时系统特征**：多路性、独立性、及时性、交互性。[cite:ac9c1640-6]

## 三、进程与线程（最核心考点）

1. **进程三种基本状态转换**：
   - 就绪 →（进程调度/分配到CPU）→ 运行
   - 运行 →（时间片用完）→ 就绪
   - 运行 →（I/O请求/等待事件）→ 阻塞
   - 阻塞 →（I/O完成/事件发生）→ 就绪
   - **就绪不能直接到阻塞**；[cite:ac9c1640-6][cite:8a4eaa16-4]
2. **进程与程序的本质区别**：进程是**动态的**，程序是**静态的**。[cite:8a4eaa16-10]
3. **进程的特征**：动态性、并发性、独立性、异步性。[cite:ac9c1640-6]
4. 时间片用完后进程挂到**就绪队列**。[cite:8a4eaa16-3]
5. 引入线程后，**独立调度和分派的基本单位是线程；资源分配的单位是进程**。[cite:8a4eaa16-3]
6. 进程由 **PCB** 表示；**一个程序不一定对应一个进程**（一个程序可对应多个进程）。[cite:8a4eaa16-1]
7. 结束一个进程实际是**撤销进程控制块 PCB**。[cite:8a4eaa16-1]
8. 五种基本状态：**新建、就绪、运行、阻塞（等待）、终止**。[cite:8a4eaa16-10]

## 四、进程同步与信号量（判断/填空高频）

1. **同步机制应遵循的规则**：空闲让进、**忙则等待**、有限等待、**让权等待**。（同步机制不应"无限等待"）[cite:8a4eaa16-3][cite:7960...]
2. 若记录型信号量 S 初值为 17，当前值为 **-17**，则表示有 **17** 个等待进程（等待进程数 = |S| 负值）。[cite:8a4eaa16-3]
3. 死锁必要条件
4. **互斥**：某资源一段时间只能被一个进程占有。
5. **请求并保持**：进程已持有至少一个资源，又等待其他进程占有的资源。
6. **不可抢占**：资源只能由占有者完成后主动释放。
7. **循环等待**：存在环 $P_0\to P_1\to\cdots\to P_n\to P_0$，每个进程等待下一个进程占有的资源。

## 五、处理机调度（少量计算）

1. **作业的三种状态**：后备、运行、完成（**阻塞不是作业状态**）。[cite:8a4eaa16-10]
2. **高响应比优先**优先级 = （等待时间 + 要求服务时间）÷ 要求服务时间 = 1 + 等待/服务。
   - 例：等待 6s、服务 6s，优先级 = (6+6)/6 = **2**。[cite:8a4eaa16-10]
3. 一个进程处于阻塞状态时，其**作业**处于**运行状态**。 [cite:8a4eaa16-1]

## 六、存储管理（选择/填空高频）

1. **段页式管理中，每取一次数据要访问 3 次内存**。（段表→页表→数据）[cite:8a4eaa16-12]
2. **分页存储产生的碎片是"内零头"**。[cite:8a4eaa16-3]
3. 动态分区存储**需要用到"紧凑"功能**（动态可重定位分区）。[cite:8a4eaa16-12]
4. "紧凑"可以得到**更大的空闲空间**。[cite:8a4eaa16-10]
5. **首次适应算法**有利于大作业装入，但使主存低、高端分区利用不均衡。[cite:8a4eaa16-3]
6. 分段存储中：段表项 = 段基址 + 段长；物理地址 = 段基址 + 段内地址；需要判断**段内越界和段号越界**。[cite:ac9c1640-5]
7. 采用**快表（TLB）**可实现逻辑→物理最快映射。[cite:8a4eaa16-1]

## 七、虚拟存储器（判断高频）

1. **抖动（Belady异常）**：页面置换算法设计不当或分配页数太少，导致频繁换页。FIFO 可能随物理块增加**缺页率反而上升**。[cite:8a4eaa16-3][cite:ac9c1640-6]
2. 虚拟存储器在**逻辑上扩充了内存**容量。[cite:8a4eaa16-3]
3. 判断某页是否在内存，根据扩充页表的**状态位 P**。[cite:ac9c1640-6]

## 八、设备与文件

1. **常用I/O控制方式**：程序直接控制、中断控制、DMA、通道方式。[cite:ac9c1640-6]
2. **虚拟设备**通过**假脱机（SPOOLing）**技术把独占设备变成共享设备。[cite:8a4eaa16-3]
3. **块设备**：软盘驱动器（硬盘、磁盘等）属块设备；鼠标、MODEM、声卡等为字符/其他设备。[cite:8a4eaa16-1]
4. **缓冲区引入目的**：缓和速度不匹配、减少中断频率、提高并行性。[cite:ac9c1640-6]
