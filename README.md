# 课程知识库

> 本仓库是基于 Obsidian 构建的课程知识库，用于将课件内容整理为结构化、可检索、可链接的 Markdown 笔记。知识库目前涵盖操作系统、计算机网络、数据库、毛概和现代密码学，所有正式笔记均以 Obsidian 核心功能能够直接解析和渲染为标准。

## 主要内容

- 课程笔记入口与当前整理状态
- 课件、笔记和配置文件的目录结构
- Obsidian 原生语法与去图片化原则
- 知识库的阅读、维护和扩充方式

## 三、笔记组织方式

### 1. 文件命名

课程章节笔记使用 `n.a 主题.md` 格式，其中 `n` 表示章号，`a` 表示节号。每门课程的“课程笔记”文件作为该课程的内容索引和阅读入口。

### 2. 笔记结构

每份课程笔记通常依次包含：

1. YAML Frontmatter；
2. 与 `title` 一致的 H1 标题；
3. 主题引言和主要内容；
4. 使用 H2、H3 组织的编号正文；
5. Obsidian 原生表格、公式、Callout 或 Mermaid；
6. 相关笔记链接与本章小结。

### 3. 知识链接

- 库内链接统一使用 `[[笔记名]]` 或 `[[路径/笔记名|显示文本]]`。
- 课程索引连接同一课程的章节笔记。
- 章节笔记通过 `related` 属性和正文链接形成关联，便于使用反向链接和关系图谱。

## 四、编写原则

### 1. Obsidian 原生优先

- Markdown、YAML、表格、公式、Callout、wikilink 和 Mermaid 均以 Obsidian 核心语法为准。
- 不依赖 Dataview、Admonition、MDX 或 HTML 表格等非核心语法。
- 所有表格强制使用 Markdown 管道表格，避免复杂渲染造成卡顿。

### 2. 笔记完全去图片化

正式笔记不嵌入图片。课件图片中的信息按照以下顺序处理：

1. 流程图、E-R 图、层次图和关系图优先重构为 Mermaid；
2. 表格重构为 Markdown 管道表格；
3. 公式重构为 LaTeX；
4. 无法可靠重构的截图、照片或复杂图表转换为完整文字描述。

最终笔记不得残留 Obsidian 图片嵌入、Markdown 图片、HTML 图片标签或 MinerU 图片路径。

### 3. 内容完整性

- 不因重新排版而遗漏定义、结论、公式、例题、表格或图片承载的信息。
- 可以根据知识逻辑调整课件顺序，但不得改变原意或凭空补充无法确认的关系。
- Mermaid 图必须实际检查语法；E-R 图使用 ASCII 实体和属性标识符，中文关系说明使用双引号。

详细规则参见 [[笔记编写要求]]。

## 五、使用方式

1. 使用 Obsidian 打开本仓库根目录。
2. 从上方课程导航或课程目录中的“课程笔记”进入对应课程。
3. 使用全局搜索、标签、反向链接和关系图谱定位知识。
4. 阅读课件时优先进入 `笔记/`，需要核对原始上下文时再查看 `课件/`。
5. 新增或修改笔记后，按照 [[笔记编写要求#八、发布前检查清单|发布前检查清单]]验证格式、链接、表格和 Mermaid。

> [!tip] 编辑器支持
> 仓库可以直接用 VSCode 编辑，但最终语法和渲染效果以 Obsidian 阅读模式为准。

---

## 六、维护约定

- 新增课件时保留原始文件名，并在相应 `笔记/` 目录创建章节笔记。
- Frontmatter 的 `source` 使用相对仓库根目录的路径。
- 文件重命名或移动后，应同步检查 wikilink、`related` 和课程索引。
- 不直接删除来源课件；重构前先确认目标笔记及其关联内容。
- 发现 Mermaid 渲染错误时，应修复兼容语法并重新检查同类图表，而不是删除图中知识。
